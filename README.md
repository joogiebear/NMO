# NMO — website redesign

Working space for a redesign of the Nina Mastro Organization website
(currently on Squarespace at ninam.org).

## Contents

- `concepts/homepage-concept.html` — a self-contained homepage design concept.
  Open it directly in a browser. It is a **proposal**, not a live site: it
  carries a concept banner, takes no donations, and every placeholder is
  labelled "slot".

## Content notes

Facts used in the concept (founded 2019, $95,000+ donated, 21 families,
diagnosis May 2015, first event June 2019 raising $8,000+, Block Party at
Shinnick's Pub, PurpleStride walk, Bunco night, giving via Venmo / bank
quick pay / check, EIN 84-2055686) are drawn from the organization's own
public pages and public 501(c)(3) records. They should be verified and
refreshed by the board before anything goes live.
